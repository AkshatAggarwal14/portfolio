Implemented the core drawing tools: brush, circle drawing with color selection, and click recognition, shipping through the v2.0 release.

Tools include brush, fill, eraser with adjustable sizes, shapes, save-to-JPG, and a draggable-path car animation. Single-file `main.cpp` on the BGI `graphics.h` library, built via a VS Code task.
